На личном устройстве пароль можно сохранить в менеджере паролей браузера. При следующем открытии он сможет предложить подстановку. Это зависит от настроек браузера.

Восстановление по резервному коду

Для этого дневника резервный код не создан. Без пароля расшифровать старые записи невозможно. Если есть скачанная резервная копия, её можно загрузить после сброса.

Для открытия нужен пароль или заранее сохранённый резервный код. Без них расшифровать записи невозможно. Копии JSON открываются без пароля.

Защитить личные записи

Придумайте пароль — он понадобится, чтобы открывать защищённый дневник.

Шифрование AES-GCM выполняется в браузере. Пароль нигде не хранится и не передаётся. Если пароль забыт, для восстановления потребуется заранее сохранённый резервный код.

Сохраните резервный код

Этот код позволит восстановить доступ, если пароль будет забыт. Он показывается только сейчас.

Сохраните его отдельно от устройства. Любой, у кого есть этот код и доступ к браузеру, может восстановить записи.

Бесплатное тестирование завершено

С 1 января 2027 года дневник доступен по оплаченному тарифу.

Войдите в зарегистрированный аккаунт с подтверждённой электронной почтой. После проверки оплаты дневник откроется на приобретённый срок.

Если доступ уже оплачен, используйте ту же электронную почту, которую указали при покупке. Покупки через Prodamus активируются только после подтверждения платежа.

    Подробнее о хранении и защите

    Записи: текст сохраняется только в текущем браузере и не отправляется в облачное хранилище дневника. Вход в тот же аккаунт в другом браузере или на другом устройстве не переносит записи автоматически.

    Аккаунт: данные регистрации и входа обрабатывает Supabase. Пароль аккаунта сам по себе не шифрует записи.

    Защита записей: включается отдельно кнопкой «Настроить защиту». После открытия защищённого дневника записи доступны человеку с доступом к этой вкладке. Перед передачей устройства нажмите «Заблокировать дневник».

    Голосовой ввод: Распознавание речи выполняет браузер или клавиатура устройства. Речь может передаваться на серверы соответствующего поставщика. Дневник сохраняет полученный текст, а не аудиозапись.

    Выгрузки: Word и резервная копия не зашифрованы. Вы самостоятельно выбираете получателя и способ передачи; перед отправкой проверьте содержимое.

    Удаление из дневника не удалит ранее скачанные файлы и резервные копии устройства.

    Дневник предназначен для самонаблюдения, не заменяет диагностику, лечение или психологическую помощь. Демо-версия: не вводите сведения, которые не готовы хранить в браузере устройства.
